## 🏫 About

This repository holds the public website of **[School Office](https://www.schooloffice.tech)**, a web-based school management ERP for K-12 schools. The site explains the product, lists its modules and lets schools book a demo.

School Office brings admissions, attendance, fees, exams, results and more into one dashboard, so a school office can stop juggling registers, spreadsheets and separate apps.

## 📦 What the product covers

The website presents the 11 integrated modules of School Office:

| 🎓 Academics | 💰 Operations | 📣 Engagement |
| :-- | :-- | :-- |
| Student directory | Fee management | Communication hub (SMS, email, app alerts) |
| Attendance | Staff HR & payroll | E-learning / LMS |
| Online exams (CBT) | Transport | Homework |
| Paper generator | Analytics | |

## 🚀 Run locally

No build step is needed.

```bash
git clone https://github.com/Muniramm890/SchoolOffice.git
cd SchoolOffice

# Option 1: open index.html directly in your browser
# Option 2: serve it locally
python -m http.server 8000
# then visit http://localhost:8000
```
