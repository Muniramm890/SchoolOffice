Getting Started

1. Registration & Login

Create your school's account and sign in for the first time.

  1. Click Register on the School Office website — this opens the sign-up form in a new tab.
  2. Enter your school name, admin email, phone number and a password.
  3. Submit the form — your school workspace is created and you're logged in as the Admin automatically.
  4. From then on, use the Login button with the same email and password to sign in.
  5. If your session expires or you're inactive for a while, you'll be signed out automatically — just log in again.
Getting Started

2. Dashboard

Your home screen after logging in — a quick snapshot of the school.

  1. See at-a-glance stats: total students, staff, today's attendance %, and pending fee collections.
  2. Use the Academic Session dropdown in the top navbar any time to switch which session's data you're viewing across the app.
  3. Recent activity and quick shortcuts to common actions appear here.
Academic Setup

3. School Setup

Do this first — it's the foundation every other module builds on.

This module has 5 tabs: Identity, Operations, Classes, Sections, Subjects.
  1. Identity tab — add your school's name, logo, address and contact details (shown on receipts, TCs and report cards).
  2. Operations tab — set working days, period timings, and general school preferences.
  3. Classes tab — add every grade you teach (e.g. Nursery to Class 12).
  4. Sections tab — add sections under each class (A, B, C...) for the current academic session.
  5. Subjects tab — add all subjects taught across the school, then link them to the relevant classes.
Academic Setup

4. Students

Add and manage your student records here.

  1. Click + Add Student to add one student at a time — fill name, admission number, class/section, guardian details and photo.
  2. Or use Bulk Import to upload a CSV of your existing student list in one go.
  3. Use the Grade / Section filters and search bar to find a student quickly.
  4. Switch between Grid view and Table view using the toggle in the top-right.
  5. Click a student card to View full details, or use Edit to update their information.
  6. If a student is leaving the school, use the Issue TC action on their card — this properly closes their record while keeping all past attendance, fees and results intact (see the Promotion & TC section).
Academic Setup

5. Teachers

Add teaching staff and assign what they teach.

Overview tab and Promote tab.
  1. Overview tab — add a new teacher with their contact details, qualification, and subjects they teach; view the full staff list.
  2. Assign each teacher to specific class-sections and subjects so they show up correctly in Timetable and Attendance.
  3. Promote tab — used when a teacher's role changes (e.g. promoted to HOD or Class Teacher).
Academic Setup

6. Promotion & TC

Run this once a year, at session-end — moves every student forward safely.

4 tabs: Overview, Promote Students, Section Transfer, History.
  1. Overview tab — pick the "From" and "To" academic session, and see how many students in each class are pending promotion.
  2. Promote Students tab — select a section, then for each student choose Promote (move to next class), Retain (repeat the class), Issue TC, or Graduate. Confirm to process the whole section at once.
  3. Section Transfer tab — move a student between sections within the same session (e.g. correcting a wrong session) — this doesn't affect their yearly history.
  4. History tab — see a log of every promotion run, with counts of promoted / retained / TC'd / graduated students.

Once promoted, a student's old class record stays exactly as it was — their fee, attendance and result history for previous years is never overwritten.

Daily Operations

7. Attendance

Mark and track daily student attendance.

4 tabs: Mark, Class, Individual, Overview.
  1. Mark tab — select a section and date, then mark each student Present/Absent/Late in one screen.
  2. Class tab — view a class's attendance for any date range in a grid.
  3. Individual tab — pull up a single student's full attendance history and percentage.
  4. Overview tab — school-wide attendance stats for the day/month.
Daily Operations

8. Substitution

Handle teacher absences by arranging cover classes.

3 tabs: Today, Overview, History.
  1. Today tab — mark a teacher absent and assign a substitute for their periods that day.
  2. Overview tab — see which periods are still uncovered.
  3. History tab — past substitution records for reference.
Daily Operations

9. Timetable

Build and share your class timetables.

2 tabs: Build, Teacher View.
  1. Build tab — pick a class from the dropdown, then click each period slot to assign a subject and teacher for every day of the week.
  2. The "X of Y periods filled" progress indicator shows how complete that class's timetable is.
  3. Teacher View tab — see any individual teacher's full weekly schedule across all their classes, to spot clashes.
Daily Operations

10. Quick Tests

For short, informal class tests outside the main exam cycle.

  1. Create a quick test — name, subject, class/section, and maximum marks.
  2. Enter marks for each student once the test is done.
  3. View a class's quick-test history any time.

12. Fee Management

Set up fee structures and collect payments.

4 tabs: Overview, Structures, Receipts, Ledger.
  1. Structures tab — define fee categories (tuition, transport, etc.) and amounts per class, for the academic session.
  2. Overview tab — see collection %, pending dues, and today's collection at a glance.
  3. Receipts tab — record a payment against a student's invoice and generate a printable receipt.
  4. Ledger tab — a student's complete fee history — invoices, payments, and balance.

13. Payroll

Manage staff salaries and payslips.

Tabs include Overview, Staff, Generate, Payslips.
  1. Staff tab — set each staff member's salary structure (basic, allowances, deductions).
  2. Generate tab — run a payroll cycle for a given month for all or selected staff.
  3. Payslips tab — view and download individual payslips once generated.
  4. Overview tab — total payroll cost and status for the month.

14. Exam Management

Set up exams, datesheets, and enter marks.

  1. Create an exam group (e.g. "Half-Yearly 2026") and add the subjects/classes it covers.
  2. Datesheet — schedule each subject's exam date and time.
  3. Marks entry — enter marks subject-wise, class-wise once exams are conducted.
  4. Publish results once all marks are entered and verified — this feeds into the Results module.

15. Results

Analyse and publish results once exams are marked.

7 tabs: Overview, Class-wise, Section-wise, Subject-wise, Teacher-wise, Toppers, Student.
  1. Overview tab — school-wide pass %, average score for the selected exam.
  2. Class-wise / Section-wise / Subject-wise tabs — drill into performance at each level.
  3. Teacher-wise tab — see how each teacher's subject sections performed.
  4. Toppers tab — auto-generated rank list per class.
  5. Student tab — pull up one student's report card and download/print it.
